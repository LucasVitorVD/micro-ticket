# Frontend Scaffold (pre-Auth0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a Next.js frontend at `frontend/` (TypeScript, App Router, Tailwind, shadcn/ui, axios) with an axios client pointed at the gateway — no Auth0 code, no login/profile pages. The user implements Auth0 themselves afterward.

**Architecture:** A single Next.js App Router project generated via `create-next-app`, styled with Tailwind and shadcn/ui components, with one axios instance (`lib/api.ts`) reading its base URL from `NEXT_PUBLIC_GATEWAY_URL`. The default home page is restyled minimally to visually confirm the whole chain (Tailwind + shadcn + axios/env) renders correctly.

**Tech Stack:** Next.js (App Router, TypeScript), Tailwind CSS, shadcn/ui, axios, npm.

**Spec:** `docs/superpowers/specs/2026-08-17-frontend-scaffold-design.md`

## Global Constraints

- No Auth0 SDK, no `middleware.ts`, no login/logout/profile routes, no session handling — the user does this themselves next.
- No Docker/compose integration — runs locally via `npm run dev` for now.
- No pages/components beyond the default home page.
- `.env.local` holds `NEXT_PUBLIC_GATEWAY_URL=http://localhost:8080` and must stay gitignored (Next.js's generated `.gitignore` excludes `.env*.local` by default — verify, don't assume).
- **Do not run `git commit` at any point in this plan.** This user only commits when explicitly asked in the conversation — stage nothing, commit nothing; just leave the working tree with the changes made. Skip every "commit" step a template might otherwise imply.
- All commands below run with the repo root (`/home/lucasvitor/Documents/java-projects/micro-ticket`) as the starting `cwd` unless a step says otherwise.

### Task 3: Install axios and create the gateway API client

**Files:**
- Modify: `frontend/package.json` (adds `axios` dependency, done by `npm install`)
- Create: `frontend/lib/api.ts`
- Create: `frontend/.env.local`

**Interfaces:**
- Produces: `@/lib/api` exporting `api`, an `AxiosInstance` with `baseURL` read from `process.env.NEXT_PUBLIC_GATEWAY_URL`. Task 4 imports this and renders `api.defaults.baseURL` to visually confirm it resolves correctly.

- [ ] **Step 1: Install axios**

```bash
cd frontend && npm install axios
```

- [ ] **Step 2: Create the env file**

Create `frontend/.env.local`:

```
NEXT_PUBLIC_GATEWAY_URL=http://localhost:8080
```

- [ ] **Step 3: Create the axios client**

Create `frontend/lib/api.ts`:

```typescript
import axios from "axios";

export const api = axios.create({
  baseURL: process.env.NEXT_PUBLIC_GATEWAY_URL,
});
```

- [ ] **Step 4: Confirm `.env.local` is actually ignored by git**

```bash
cd frontend && git check-ignore -v .env.local
```

Expected: prints a match against the `.gitignore` rule confirmed in Task 1 Step 3. If it prints nothing, `.env.local` is NOT ignored — stop and fix `.gitignore` before continuing (do not let this file get staged later).
